CLI (Baris Perintah)

Satu perintah untuk mengenkripsi atau mendekripsi berkas.

$ npx baronglock notes.txt
$ npx baronglock notes.baronglock

Perintah npx tersedia setelah paket dipublikasikan ke npm.

Mulai Menggunakan

Gunakan Node.js dan npm/npx. Tidak perlu menginstal dependensi runtime tambahan.

git clone https://github.com/baronglock/baronglock.git
cd baronglock
npm test

Menemukan file .baronglock?

Kunjungi repository dan dokumentasi resmi untuk mempelajari cara membukanya. Anda tetap memerlukan kunci yang cocok atau akses ke layanan pengelola kunci yang sah.
