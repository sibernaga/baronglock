Command-Line Interface

One command to lock or unlock a file, with a key or a password.

$ npx baronglock notes.txt
$ npx baronglock notes.txt --password
$ npx baronglock notes.baronglock

Available on npm. Requires Node.js 20 or newer.

▤

File Format

.blj

BarongLock Container

A versioned encrypted format with authentication to detect data tampering.

Extensions: .baronglock or the short form .blj. Both are the same format.

Get Started

Use Node.js and npm/npx. No extra runtime dependencies are required.

git clone https://github.com/sibernaga/baronglock.git
cd baronglock
npm test

VS CODE EXTENSION

Edit locked files
right in VS Code

Click a .blj or .baronglock file and it opens as normal text. Save, and it is locked again. The file on disk is never left unlocked.

  • Open locked files with one click
  • Every save locks the file again, the same way
  • Lock any file from the Explorer, with a key or a password
  • Also for Cursor and VSCodium, through Open VSX
code --install-extension sibernaga.baronglock-vscode
