Command-Line Interface

One command to encrypt or decrypt a file.

$ npx baronglock notes.txt
$ npx baronglock notes.baronglock

Available on npm. Requires Node.js 20 or newer.

File Format

.blj

BarongLock Container

A versioned encrypted format with authentication to detect data tampering.

Extensions: .baronglock or the short form .blj. Both are the same format.

Get Started

Use Node.js and npm/npx. No extra runtime dependencies are required.

git clone https://github.com/sibernaga/baronglock.git
cd baronglock
npm test
View GitHub Repository ↗

Found a .baronglock or .blj file?

Visit the repository and documentation to learn how to open it. You will still need the matching key or authorized access to a key-management service.
